connection_service.py

Credentials encrypted at rest (Fernet, CREDENTIAL_ENCRYPTION_KEY) and never touch the AI. Introspection caches schema shape only — table & column names, no sample rows.

Sandbox test
heal_pipeline.py

Ephemeral python:3.10-slim container. Runs the generated dlt script against the real destination, network-isolated except for the declared source/destination.

self-healing loop · bounded, max 3 attempts
run → fails → AI reads traceback → patches & retries
exhausted → pipeline returns to draft, nothing silently retried forever
4
Human review gate
review_api.py

Code diff, sandbox log, and a place for a reviewer's reasoning — the one place in the loop where a person, not a model, makes the call.

✓ approve → pinned, schedulable
✕ reject → comment feeds the next generation attempt
5
Schedule
schedule_service.py · APScheduler

Pinned to the exact pipeline_version_id that was reviewed — a later edit can never silently change what an approved schedule actually runs. Restored from Postgres on every backend restart.

cron_expression next_run_at persisted runs pinned code only, never regenerates
